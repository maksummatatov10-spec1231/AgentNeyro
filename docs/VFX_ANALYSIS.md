## Типы файлов (всё нативное для Godot 4)
- `.gdshader` / `.gdshaderinc` — шейдеры Godot (spatial, частицы).
- `.tscn` — готовые сцены эффектов (instance и играй).
- `.tres` — материалы/ресурсы (множество вариантов снарядов/вспышек).
- `.gd` — скрипты-контроллеры: `VFXEmitterBB`, `VFXOmniLightBB`, `VFXControllerBB`, `VFXImpactBB`, `vfx_beam_controller`.
- `.ptex` — текстовый JSON-формат Binbun (граф-описание эмиттеров/частиц).
- `.uid` — идентификаторы ресурсов Godot 4 (надёжные ссылки).
- `.png` — текстуры вспышек (1024²) и иконки (128²).
- `.hdr` — студийные окружения (story_studio) для превью-сцен.
- `.obj` — `suzanne.obj` (тест-меш для showcase-сцен — можно удалить).

## ⚙️ Технические заметки
1. ✅ **Прямой импорт в Godot 4.7** — скопировать папку в `res://`, эффекты-`.tscn` инстансить где нужно.
2. ⚠️ При копировании между проектами UID-ссылки (`uid://`) сохраняются; если пути «бьются» — пере-импорт.
3. `.ptex` — кастомный формат BinbunVFX; зависит от их скриптов-эмиттеров (`.gd`), копировать вместе.
4. Эффекты — одноразовые (one-shot): инстансить через `PackedScene.instantiate()` и удалять после проигрывания (или пул).
5. Showcase-сцены с `suzanne.obj`/`*.hdr` — только для превью, в игру не нужны.
6. Все текстуры 1024² (кроме иконок 128²) — единый масштаб с остальными ассетами.
