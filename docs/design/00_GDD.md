# 🎮 EMBERFALL — Game Design Document (v1.0)

> **Кодовое название:** EMBERFALL · **Жанр:** Dungeon Escape FPS / Action
> **Движок:** Godot 4.7.1 (GDScript) · **Вид:** от первого лица
> Статус: дизайн завершён, переход к производству.

---

## 1. Концепция (Elevator Pitch)

Ты очнулся в глубинах ожившего некрополиса. Запас факелов тает, орды скелетов бродят
между колонн, а пол скрывают ловушки. **Цель — вырваться наружу**, где тебя ждут друзья.
Бей мечом, жги врагов магическими снарядами и лучами, уворачивайся от ловушек — иди
сквозь тьму к свету выхода. Короткая, плотная, **красивая** аркада: ~15–25 минут чистого
напряжения с «шедевральной» картинкой на Ultra.

**Слоган:** *«Факел гаснет. Ты — нет.»*

---

## 2. Core Game Loop

```
СПАВН (тёмная камера)
   → ИССЛЕДОВАНИЕ коридоров/комнат (свет факелов, поиск пути)
   → БОЙ со скелетами (меч + магия) / ИЗБЕГАНИЕ ловушек
   → ПРОГРЕСС: комнаты → ключ/рычаг → запертый гейт
   → [поражение?] respawn у последнего костра / смерть → экран Game Over
   → ВЫХОД на поверхность → ДРУЗЬЯ встречают → ЭКРАН ПОБЕДЫ
```

**Цикл напряжения:** безопасность комнаты ↔ опасность коридора/трапа ↔ пик боя ↔ награда (путь вперёд / лут).

---

## 3. Сеттинг и нарратив

- **Мир:** Подземный некрополь древнего ордена. Пробуждён артефактом, поднял мёртвых.
- **Герой:** Один из авантюристов (по умолчанию **Knight**), владеет клинком и боевой магией.
- **Цель:** Добраться до Врат Света (выход). По пути — собрать 1–2 **ключа/активировать рычаги**,
  чтобы открыть гейт перед выходом.
- **Друзья у выхода:** **Knight, Mage, Ranger** стоят у выхода, приветствуют героя (финальная сцена).
- Тон: мрачный, атмосферный, с искрами надежды (факелы, свечи, свет выхода).

## 6. Враги (скелеты, риг Rig_Medium — один общий для всех)

| Враг | HP | Скор. | Урон | Поведение | Источник-ассет |
|---|---:|---:|---:|---|---|
| 💀 **Minion** | 40 | 3.5 | 8 | рой, лезет вплотную | Skeleton_Minion |
| ⚔️ **Warrior** | 90 | 3.0 | 18 | танк, блокирует, бьёт мечом | Skeleton_Warrior |
| 🗡️ **Rogue** | 55 | 4.5 | 12 | быстрый, флангует | Skeleton_Rogue |
| 🔮 **Mage** | 50 | 2.5 | 15 (дальний) | держит дистанцию, кастует **снаряды/тёмную магию** | Skeleton_Mage |
| 👑 **Bone Lord** (мини-босс) | 400 | 3.0 | 28 | фазы, призыв миньонов, даёт ключ | Skeleton_Warrior (увелич.) |

**AI:** NavigationAgent3D (NavMesh по полу данжа), состояние-машина: `Idle → Alert → Chase → Attack → Hurt → Dead`.
Линия видимости (raycast) для обнаружения; потеря игрока → возвращение/поиск.

### Анимации врагов (из Rig_Medium, общие):
`Idle_A/B` (стоят), `Walking_A/B/C`, `Running_A/B` (преследование),
`Hit_A/B` (**реакция на урон**), `Death_A/B` (+`_Pose`) (смерть),
`Spawn_Air/Spawn_Ground` (появление/призыв), `Interact/PickUp/Throw/Use_Item`.

## 8. Уровень (Level Design)

- **Сборка:** модульные тайлы данжа (полы/стены/колонны/лестницы) собираются скриптом
  `DungeonBuilder` на сетке 1 м в N комнатах (цель 8–12), соединённых коридорами.
- **Структура:** Спавн-камера → Коридоры → Комнаты с врагами/ловушками/лутом →
  Комната мини-босса (ключ) → Запертый гейт → Финальный коридор → **Врата Света (выход)**.
- **Освещение:** факелы (`torch`), свечи (`candle_lit`), редкие AreaLight3D (Ultra),
  объёмный туман. Тьма = часть геймплея (видишь только в свете факела).
- **NavMesh:** генерируется по полу (NavigationRegion3D) для врагов.
- **Выход/друзья:** триггер-зона у ворот → спавн 3 друзей → fade → экран победы.

## 9. UI / Меню (см. `02_GRAPHICS_TIERS.md` для графики)

```
ГЛАВНОЕ МЕНЮ
├─ ▶ Играть (выбор/новая игра → уровень)
├─ ⚙ Настройки
│   ├─ 🎮 Геймплей (чуств. мыши, инверсия, FOV, субтитры, чекпоинты)
│   ├─ 🔊 Звук (громкость Master/Music/SFX/UI, язык)
│   ├─ ⌨ Управление (ребинд, мёртвая зона геймпада)
│   └─ 🖼 ГРАФИКА ← большое меню (Low→Ultra, ~25 параметров)
├─ 📜 Достижения/Прогресс (опц.)
└─ ⏏ Выход
```
Во время игры: **HUD** (HP/MP/STA, способность, цель, компас к выходу),
**пауза (Esc)** → продолжить/настройки/в меню, **экраны победы/смерти**.

---

## 10. Геймплей-циклы состояний игры

`BOOT → MAIN_MENU → (SETTINGS) → LOADING → LEVEL ↔ PAUSE → WIN/LOSE → MAIN_MENU`

**Победа:** герой входит в зону выхода → друзья оживают/поворачиваются → fade → карточка结局 + кнопки (заново/меню).
**Поражение:** HP=0 → экран смерти → respawn у чекпоинта (если есть жизни) или в меню.

---

## 11. Звук (план)

- **Музыка:** мрачный эмбиент в исследовании, нарастающий tension в бою, триумф в финале.
- **SFX:** шаги (камень), удары меча (whiff + impact), каст магии, попадания, кости скелетов,
  ловушки (шипение/щелчки), дыхание/сердцебиение при низком HP, UI-клики.
- **3D-звук:** позиционный для врагов/ловушек/факелов.

## 12. Критерии качества («высший уровень»)

- ✅ Стабильный 60+ FPS на Medium (GTX 1060-класс), 144 на High, «шедевр» на Ultra (RTX-класс).
- ✅ Чёткий читаемый геймплей: враги и ловушки телеграфированы.
- ✅ Сочный джус: HitFX, тряса камеры, vignette, slow-mo на убийстве босса.
- ✅ Полная цепочка меню и настроек с применением в реальном времени.
- ✅ Документация покрывает каждый модуль (этот набор docs/).
