## Краткое резюме игры
**Жанр:** Dungeon Escape FPS/Action · **Движок:** Godot 4.7.1 · **Вид:** от первого лица.
Герой спавнится в подземелье, пробивается через скелетов и ловушки (меч + магия:
снаряды/луч/AoE), находит ключ, открывает гейт и выходит на поверхность, где его
встречают друзья-авантюристы. Большое меню графики Low→Ultra, «шедевральная» картинка на Ultra.
