# ⌨️ Управление (EMBERFALL)

| Действие | Клавиша | Примечание |
|---|---|---|
| Движение | **W A S D** | + стрелки |
| Прыжок | **Space** | |
| Спринт | **Shift** (удерж.) | тратит выносливость |
| Присед | **Ctrl** / **C** | ниже профиль, тише |
| Взаимодействие | **E** | двери, рычаги, предметы |
| ⚔️ Удар мечом (лёгкий) | **ЛКМ** | комбо из 3 |
| ⚔️ Тяжёлый удар | **R** (или удерж. ЛКМ) | стан, тратит STA |
| 🔵 Магический снаряд | **ПКМ** | шар-болт, тратит MP |
| 🟣 Магический луч | **F** (удерж.) | канал, MP/сек |
| 🟠 Огненный взрыв | **Q** | AoE, КД 6 с |
| 💚 Исцеление | **H** | +HP, КД 8 с |
| 💛 Рывок/Блинк | **E** (контекст) / Shift×2 | i-frames |
| Сменить оружие | **1**/**2** / колесо мыши | меч ⇄ посох |
| Пауза | **Esc** | меню паузы |
| Интерфейс UI | стандартные `ui_*` | навигация в меню |

**Геймплей-настройки (меню):** чувствительность мыши, инверсия Y, FOV (75–110),
интенсивность head-bob, субтитры, подсказки, чекпоинты (вкл/выкл), тряска камеры.

> Поддержка геймпада зарезервирована (мёртвые зоны, ребинд в меню «Управление»).
