# ⚔️ Боевая система, способности и магия (EMBERFALL)

> Подробная спецификация боя: ближний бой (меч), дальняя магия (снаряды/луч/AoE),
> реакции на урон у игрока и врагов, VFX/SFX на каждое действие.

---

## 1. Ресурсы игрока
| Ресурс | Макс | Регенерация | На что тратится |
|---|---:|---|---|
| ❤️ HP | 100 | +5/с (после 5 с без урона) | получение урона; 0 = смерть |
| 🔵 MP | 100 | +8/с | магические способности |
| 🟡 STA | 100 | +25/с (после 1 с) | спринт, тяжёлый удар |

---

## 2. Ближний бой — МЕЧ (Sword)

### 2.1 Лёгкая серия (Light Combo) — ЛКМ
- **Combo-цепочка из 3 ударов**, каждый следующий клик в окне 0.3 с продлевает комбо.
- Урон: **18 → 20 → 26** (третий — добивающий с отбросом).
- Длительность замаха: 0.45 с, окно хит-детекта: 0.10–0.22 с после старта.
- Угол конуса поражения: 100°, дальность: 2.2 м.
- **Viewmodel-анимация:** клинок делает диагональные замахи (анимация меча камеры,
  по кадрам: замах назад → рубка вниз/вбок). Реализуется Tween/AnimationPlayer на ноде клинка.
- **VFX на удар:** свечение лезвия (emissive trail), по попаданию — **HitFX** (`vfx_impact_slash`).
- **SFX:** whiff (свист) + impact (металл/кость).

### 2.2 Тяжёлый удар (Heavy) — удержание ЛКМ / `R`+ЛКМ
- Урон: **35**, стан врага 0.5 с, широкая дуга.
- Длительность 0.8 с, расход 25 STA, нельзя двигаться во время замаха.
- Сбивает миньонов с ног (ragdoll-lite).

### 2.3 Парирование/блок (опц.) — ПКМ в режиме меча
- Поднимает щит/клинок, снижает урон на 70%, открывает окно контратаки.

> Ассеты: `sword_1handed.fbx` (viewmodel), `sword_2handed.fbx` (тяжёлый вариант),
> щиты `shield_*` (для блока). Эффекты: **HitFXFree** (slash/impact).

## 3. МАГИЯ (Magic) — те самые «шары-снаряды» и не только

### 3.1 🔵 Магический снаряд (Bolt) — ПКМ (режим магии) / колесо мыши
- **Главный дальний выстрел:** летящий **энергетический шар** с ядром+хвостом.
- Стоимость: **12 MP**, КД 0.35 с, урон **25**, скорость 22 м/с, радиус попадания 0.5 м.
- При попадании: вспышка + AoE-урон (радиус 1 м, 8 доп.) + **HitFX impact**.
- **Реализация:** сцена `Projectile` (Area3D + MeshInstance3D + PointLight3D + Trail).
  Внешний вид = материалы из **MagicProjectilesVFX** (`mprojectile_basic_*_core/head/trail`).
  Направление = взгляд камеры.
- **VFX:** MagicProjectiles (снаряд) + HitFX (попадание) + OmniLight синий.

### 3.2 🟣 Магический луч (Beam) — `F` (удержание)
- **Канал:** непрерывный луч из посоха, пока удерживаешь и есть мана (**6 MP/с**).
- Урон: **22/с**, радиус действия по линии видимости (raycast), дрожание цели.
- **VFX:** **GodotBeamVFX** (`beam_core/outer/flare/ball` + `glow_particle`).
- Обрывает дистанцию, хорош против танков; враги пытаются уклониться.

### 3.3 🟠 Огненный взрыв (Fireball/AoE) — `Q`
- Кастует огненный шар, который летит и **взрывается** (радиус 4 м).
- Стоимость: **35 MP**, КД 6 с, урон **60** центр / 30 край, поджигает (DoT 5/с ×3 с).
- **VFX:** **ExplosionFX** (`explosion_core/rings/impact`) + частицы огня + тряска камеры.

### 3.4 💚 Исцеление (Heal) — `H`
- Стоимость: **30 MP**, КД 8 с, **+35 HP**.
- **VFX:** зелёное свечение вокруг рук/камеры + поднимающиеся частицы (своя сцена или ElementalMagicFX).

### 3.5 💨 Рывок/Блинк (Dash) — двойной Shift / `E`
- Стоимость: **15 MP**, КД 2 с, телепорт 6 м по направлению движения, **i-frames** во время рывка.
- **VFX:** стрик/послеобраз (after-image) + лёгкий ударный эффект на старте.

### 3.6 (Будущее) 🔮 Стена щита / ⚡ Цепная молния / ❄ Заморозка
- Резерв способностей для расширения; кодовая архитектура позволяет легко добавлять.

> Ассеты-эффекты: MagicProjectiles, GodotBeam, ExplosionFX, ElementalMagicFX, DarkMagicFX.

## 4. Реакции на урон — ВРАГ (Enemy Hurt)

При попадании по врагу срабатывает **пакет отклика**:
1. **Урон** (вычет HP) + всплывающее **число урона** (опц.).
2. **Вспышка материала:** emissive → белый на 0.1 с (shader override или `material_overlay`).
3. **Анимация `Hit_A` / `Hit_B`** (чередуются) — отшатывание; прерывает атаку врага.
4. **Knockback** по направлению удара (импульс через NavigationAgent/velocity).
5. **HitFX** на точке попадания (`vfx_impact_01/02`, slash, flare, streaks).
6. **SFX:** хруст кости + звук удара.
7. Если HP ≤ 0 → переход в **Death** (см. ниже).

### Смерть врага
1. Анимация **`Death_A`** (или `Death_B` рандомно) проигрывается ~1.2 с.
2. **Дисcolve-шейдер** (растворение в прах) поверх скелета.
3. **ExplosionFX/прах** (у Mage — тёмный взрыв DarkMagicFX).
4. Дроп: **мана-сфера** (+15 MP) / редко HP. Подбирается автоматически.
5. Удаление ноды после анимации (или pooled).

## 5. Реакции на урон — ИГРОК (Player Hurt)

При получении урона игроком:
1. **Красный vignette** по экрану, интенсивность ∝ урону (макс при >25).
   - Управляется `ColorRect` с radial-gradient шейдером, плавно затухает 1.5 с.
2. **Тряска камеры** (camera shake): амплитуда ∝ урон, затухание 0.4 с.
3. **HitFX-искры** в направлении удара (по позиции попадания, если raycast).
4. **Полоса HP** мигает, число «-N» всплывает.
5. При **HP < 30:** постоянный пульсирующий красный vignette + **сердцебиение** (SFX loop) + искажение.
6. **HP = 0 →** slow-mo (0.3×) 1 с → fade → **экран смерти**.

Источник урона: контакт-атака врага, ловушки, падение блока, газ.

---

## 6. Состояния игрока (State Machine)

`IDLE → MOVE → SPRINT → CROUCH → JUMP/FALL →
ATTACK(light/heavy) → CAST(bolt/beam/aoe/heal) → DASH(invuln) → HURT(no-control short) → DEAD`

Во время каста/атаки — ограничение скорости (walk), поворот телом не блокируется (только камера).

---

## 7. Баллистика и хит-детекция

- **Меч:** конус (Area3D перед игроком) в окне активности; собирает врагов, применяет урон+knockback.
- **Снаряд:** `Area3D.entered` по врагам/стенам; физ-тело летит по направлению взгляда.
- **Луч:** `RayCast3D` от камеры, первая цель в дальности получает DoT; обновляется каждый кадр.
- **AoE:** сфера `Area3D` в точке взрыва, урон по всем внутри с учётом расстояния.
- **Урон по игроку:** `Area3D` врага/ловушки + контактная атака врага по таймеру.

## 9. Feel / Juice (полировка)
- Hit-stop (микро-замораживание времени на 40 мс) при тяжёлом ударе/убийстве.
- Slow-mo в финальном убийстве мини-босса.
- Тряска камеры шкалируется; плавная кривая затухания.
- Частицы пыли при шагах по камню; искры от факелов.
- Звуковая палитра: низкие «бумы» на взрывах, хруст на ударах, звон на блоках.
